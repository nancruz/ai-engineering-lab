Commands

Run from your project folder (projects/knowledge-assistant/). Every command takes the shared options below.

CommandWhat it doesUseful options
doctorLab progress (runs each lab's tests), data location, optional tools
search "query"Retrieve chunks and show their scores--explain (BM25 term scores)
chunks DOC_IDShow how one document is chunked--full
ask "question"Answer with citations--show-prompt
evalScore retrieval (and answers) on the labelled questions--compare a,b,c --answers --judge LLM --split dev|test|all --type T --questions FILE --show-failures --out FILE
indexSync documents into the SQLite index--db PATH
serveRun the HTTP API (POST /ask, GET /health)--host --port

Glossary

AbstentionAnswering "I don't know" when the sources don't contain the answer. Often the correct output.
ANNApproximate nearest neighbour search (e.g. HNSW): fast vector search that may miss some true neighbours.
BM25Keyword ranking function using term rarity (IDF), saturated term frequency (k1) and length normalization (b).
ChunkThe unit that is indexed and retrieved: a slice of a document with its id, heading and offsets.
Context windowThe maximum number of tokens a model can read in one request, prompt and answer included.
Cosine similarityCosine of the angle between two vectors; equals the dot product for normalized vectors.
Cross-encoderA model that scores a (question, passage) pair by reading both together; used for reranking.
EmbeddingA vector representation of text in which similar meanings point in similar directions.
Evidence foundThis course's passage-level metric: the share of labelled evidence strings inside the retrieved chunks.
FaithfulnessWhether an answer's claims are supported by its sources (often judged by an LLM).
Hybrid searchCombining keyword and vector retrieval, usually with reciprocal rank fusion.
IDFInverse document frequency: a term's weight, higher when fewer documents contain it.
Inverted indexMap from each term to the documents that contain it.
MRR, nDCG, recall@kRanking metrics: position of the first hit; graded credit by position; share of relevant items found.
Prompt injectionInstructions hidden in input text (here, retrieved documents) that try to change the model's behaviour.
RerankerA second-stage model that reorders a shortlist of candidates more precisely.
RRFReciprocal rank fusion: merge rankings by summing 1 / (c + rank).
TokenThe unit models read and bill: roughly ¾ of an English word, about 4 characters.

Reading list

  • Lewis et al. (2020), Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks: the paper that named RAG.
  • Robertson & Zaragoza, The Probabilistic Relevance Framework: BM25 and Beyond.
  • Sentence Transformers documentation: embeddings, cross-encoders, retrieve & re-rank.
  • Anthropic, Introducing Contextual Retrieval.
  • Liu et al. (2023), Lost in the Middle.
  • Cormack et al. (2009), Reciprocal Rank Fusion.
  • Ragas documentation, for RAG evaluation metrics.
