RAG COURSE · AI ENGINEERING LAB

Build a RAG system from scratch.
Understand every piece.

Seven modules. Each one explains a single idea with interactive visuals that run on a real knowledge base, then you build that piece in Python and prove it works with tests. You finish with a RAG service that searches, cites its sources, refuses when it should, is measured, and runs behind an API.

7 modules + capstone≈ 30–35 hoursPython standard libraryoptional: Ollama, OpenAI, Anthropicno quizzes

How every module works

LEARN · 15–25 MIN

One focused idea, made visible

A short page that explains what the technique does and why, with widgets you can play with: change BM25's parameters, drag vectors, re-chunk a runbook, assemble a prompt under a token budget. They compute on the course's real documents.

BUILD · 2–5 H

Write it, run it, measure it

A lab in minirag, one Python package that grows module by module. You get starter code with TODOs, tests that tell you when you're done, experiments to run on the knowledge base, and a reference solution.

There's nothing to hand in and no theory questions. The tests and the numbers your own system produces tell you how you're doing.

RAG in one picture

Retrieval-augmented generation answers a question in two steps. First it retrieves the few passages from your documents that matter, then it has a language model generate an answer from those passages only, with citations. What you need

  • Python 3.10+, git and a terminal. You should be comfortable reading and writing Python; no machine-learning background is assumed.
  • Nothing else for the core labs. They run offline on the standard library, with simple stand-ins for models.
  • Optional, recommended from Module 2: Ollama for free local models, or an OpenAI-compatible or Anthropic API key. Docker for Module 7.
