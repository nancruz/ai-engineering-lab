AI Engineering Lab

The course is edited directly in HTML. Open the learning path to begin.

Edit and preview

Edit lesson files under docs/lessons/ or guides under docs/guides/, then refresh your browser. Shared styles and interactions live in docs/assets/. There is no generator or website build dependency.

Open docs/index.html directly, or use any static server for full-text search. With Python already installed:

python3 -m http.server 8000 --directory docs

Publish

In repository Settings → Pages, select Deploy from a branch, choose main and /docs, then save. GitHub serves the committed files directly. Repository visibility and your GitHub plan still determine Pages availability.

Runnable labs

The Python training exercises remain in tracks/rag/lab/. Your application grows in projects/knowledge-assistant/. Consult the project contract and AWS guide while following the lessons.
