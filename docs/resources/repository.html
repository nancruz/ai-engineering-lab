COURSE MATERIAL

AI Engineering Lab

A hands-on learning repository for an experienced software engineer developing AI engineering skills. Study budget: three hours per week. Basic Python and software scaffolding are assumed; unfamiliar AI concepts are taught before the experiments that use them.

Start here

The first active track is Applied AI Engineering through RAG. Begin with What a RAG system is, then follow Module 1, Week 1.

This repository is the current source for lessons, exercises, code and evaluation artifacts. Notion is a navigation and planning dashboard; its older lesson pages and downloads are snapshots.

Repository map

Location Purpose

Keep dependencies and environments local to each project or track. Add a new track when you start studying it; potential later tracks include model training, multimodal systems and agent workflows. The repository name supports all of them without committing to a speculative curriculum now.

Working rhythm

Each week has three one-hour practical sessions with explicit actions, saved outputs and completion checks. Theory is reference material; progress comes from running, changing and debugging the application. Setup and debugging count toward the budget. Commit your experiment question, configuration, results and interpretation together. If a task takes longer, continue next week rather than adding hidden homework.

The supplied starter lab runs locally without API keys. Later work adds real models and deployment. The course develops evidence of engineering ability; completing reading or toy benchmarks alone does not establish readiness for an AI engineering role.

The final 12 learning weeks focus on deploying and operating RAG on AWS, including persistence, identity, CI/CD, observability, load testing, rollback and backup restore.
