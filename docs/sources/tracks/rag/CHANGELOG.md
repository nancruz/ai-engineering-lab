# Course revision — 21 October 2026

The full eight-module path now follows one evolving application with specific session actions, file locations, saved outputs, completion checks and next steps.

- Theory remains reference material; written theory answers, oral defenses and grading-style assessments are removed.
- The first real generator call moves to week four, followed by your own CLI/API in weeks five and six.
- A label-hiding question viewer and minimal local Ollama RAG helper make the first tasks runnable.
- Retrieval, ingestion, evaluation, applied ML and neural adaptation now produce application components or reproducible experiments.
- Modules 7–8 dedicate 12 learning weeks to production preparation and operation: identity, pgvector persistence, ingestion publication, containers, AWS staging, CI/CD, observability, load/cost limits, recovery, promotion and teardown.
- One project contract and one AWS path replace repeated navigation and unspecified platform choices.
- Completed work remains valid. Resume at the next uncompleted operation; do not restart the course.

The 3-hour weekly budget and four consolidation weeks remain. Cloud resources and finished learner implementations are not created by revising the course.
