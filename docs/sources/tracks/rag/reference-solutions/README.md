# Numerical reference solutions

`math_labs.py` contains a small logistic-regression training example, a finite-difference gradient check and causal attention mechanics. Attempt the corresponding exercises in Modules 5 and 6 before reading it.

From this directory, in a virtual environment with NumPy installed:

```bash
python3 math_labs.py
```

This is a reference on generated data, not a complete evidence-gating model or a trained language model. The runnable retrieval baseline lives separately in [lab/](../lab/README.md) and may be used immediately.
