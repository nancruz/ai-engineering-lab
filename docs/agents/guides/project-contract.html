Project contract — ops agent

One project, consistent paths and interfaces, so every week builds on the last. The lessons refer to this page whenever they name a file or a record. You may change internals freely; keep these interfaces stable or update this contract in your copy when a decision record changes them.

Directory map

projects/ops-agent/
  app/
    loop.py              # run(task, model, tools, config) -> run summary; writes trajectory.jsonl   (M1)
    models/              # provider adapters + scripted stubs for tests                              (M1)
    workflows/           # fixed-sequence versions of tasks, for comparison                           (M1)
    tools/               # one module per tool: contract + run(args, ctx)                             (M2)
    context.py           # token accounting, caps, compaction, facts ledger                           (M3)
    state.py             # checkpoints, resume, approval pause                                        (M3)
    memory.py            # notes with provenance, scope and expiry                                    (M3)
    gate.py              # authz, approvals, egress allowlist, taint hold, kill switch                (M4, M7)
    graders.py           # outcome, trajectory and rubric graders                                     (M5)
    orchestrator.py      # lead and workers, hand-off schemas                                         (M6)
    tracing.py           # OpenTelemetry spans                                                        (M7)
  mcp_server.py          # read-only tools over MCP                                                   (M2)
  configs/
    agent.json           # model IDs, budgets, harness switches
    release-policy.json  # hard gates and soft targets                                                (M5)
  data/
    tasks/dev.jsonl      # development tasks
    tasks/final.jsonl    # held-out tasks; run only with --final
    fixtures/            # fictional documents, injections, tracker states
  artifacts/
    runs/<run-id>/       # trajectory.jsonl, summary.json, checkpoint.json
    evals/<eval-id>/     # report.json and per-trial summaries
    decisions/           # numbered decision records
    security/            # threat model, red-team log
    releases/<id>/       # manifest.json
  tests/                 # offline: no network, scripted models
  Makefile

Create directories when a lesson first needs them. Keep secrets out of the repository; read API keys from the environment.

Model adapter

def turn(messages: list[dict], tools: list[dict], config: dict) -> dict:
    """Returns {
      "tool_calls": [{"id": str, "name": str, "args": dict}],   # may be empty
      "text": str | None,                                      # final answer when no tool calls
      "stop_reason": str,                                      # provider's reason, normalised
      "usage": {"input_tokens": int, "output_tokens": int},
      "model": str,                                            # exact model ID that answered
      "raw": dict                                              # provider response, for the log
    }"""

Messages use a neutral format: {"role": "system"|"user"|"assistant", "content": str}, assistant tool requests as {"role": "assistant", "tool_calls": [...]} and results as {"role": "tool", "tool_call_id": str, "name": str, "content": str}. Each adapter converts to and from its provider.

Tool

name: str                 # snake_case, unique
description: str          # when to use, when not to, what it returns, approval needs
input_schema: dict        # JSON Schema; additionalProperties: false
side_effect: bool
approver_roles: list[str] # empty for read-only tools
timeout_s: float
def run(args: dict, ctx: RunContext) -> dict   # ctx carries caller role, run ID, taint flag

Errors use one envelope, so the model and your graders can rely on it:

{"error": "invalid_arguments", "message": "Fix the listed fields and call again.",
 "details": [{"path": "$.minutes", "problem": "must be of type integer"}], "retryable": false}
CodeRetryableMeaning
invalid_argumentsNoSchema validation failed; details lists each problem.
not_foundNoThe requested object does not exist or is not visible to the caller.
forbiddenNoThe caller's role may not do this.
approval_requiredNoA side effect without a valid approval for these exact fields.
conflictNoIdempotency key reused with different fields.
repeated_callNoHarness refused an identical call.
timeout, rate_limited, upstream_errorYesTransient; the harness may retry with backoff.
unavailableNoCircuit open or kill switch on.
