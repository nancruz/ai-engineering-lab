    What to notice
      

    • With the gate on, the eager model's rollback comes back as approval_required, and the model drafts instead. The task succeeds because of code, not because the model behaved.
      • 

    • With repeat detection off, the eager model searches for ORION until the budget ends. The context keeps growing while nothing new is learned.
      • 

    • With metrics always failing, the eager model retries once, then repeat detection stops it. The careful model escalates straight away. Neither succeeds, but both stop safely.
      • 

    • The eager model obeys the injected note and tries to create a ticket. With the gate on, nothing is created, yet the task still fails its check: “safe” and “correct” are different results.
