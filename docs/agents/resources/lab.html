Agents / Lab commands

COURSE MATERIAL

Supplied lab commands

Follow the modules for the ordered exercises; this page is a command reference. All commands start at the repository root and use only the Python standard library unless noted. The lab has its own small BM25 retriever (retrieval.py) and fictional corpus (data/corpus.json).

Tests

python3 -m unittest discover -s tracks/agents/lab -p 'test*.py' -v
python3 -m unittest tests/site/test_site.py -v     # site checks; needs node for the browser-parity tests

The site tests run the browser workbench code in Node and compare its results with the Python lab, so the workbenches always show what the lab computes.

Agent runs

python3 tracks/agents/lab/run.py --task rollback-check
python3 tracks/agents/lab/run.py --task rollback-check --model scripted:eager --no-gate
python3 tracks/agents/lab/run.py --task orion --model scripted:eager --no-repeat-check --max-steps 6
python3 tracks/agents/lab/run.py --task rollback-check --fault timeout_always --no-retry
python3 tracks/agents/lab/run.py --task injected-note --model scripted:eager --out /tmp/injected.json
OptionEffect
--model scripted:carefulDefault deterministic model that follows policy.
--model scripted:eagerDeterministic model that acts first: rolls back, follows the injected note, repeats searches.
--model ollama:<tag>Real local model through real_model.py.
--max-steps NModel-turn budget (default 6).
--fault timeout_once|timeout_alwaysMakes the metrics tool time out.
--no-retryThe harness does not retry transient errors.
--no-repeat-checkIdentical repeated calls are allowed.
--no-gateSide-effecting tools run without approval (fictional world only).

Guardrails and grading

python3 tracks/agents/lab/guard.py                       # all defenses
python3 tracks/agents/lab/guard.py --defenses=            # none
python3 tracks/agents/lab/guard.py --defenses=require_approval,bind_approval
python3 tracks/agents/lab/grading.py -k 3
python3 tracks/agents/lab/grading.py -k 3 --max-steps 10 --no-citation-grader

MCP reference server

python3 -m pip install "mcp[cli]"                         # not standard library; pin the version you get
npx @modelcontextprotocol/inspector python3 tracks/agents/lab/mcp_server.py

Files

  • agent.py — environment, tools, scripted models, loop and end-state checks.
  • schema.py — JSON Schema subset validator and tool-description review.
  • guard.py — layered action gate over the scenario fixtures.
  • grading.py — trial grading, pass@k and pass^k.
  • real_model.py — Ollama adapter.
  • mcp_server.py — read-only tools over MCP.
  • run.py — command-line runner.
  • Fixtures: world.json, tools.json, tasks.json, guard_scenarios.json, trials.json.

The trial fixture is invented to practise grading. It is not a measurement of any real model.
