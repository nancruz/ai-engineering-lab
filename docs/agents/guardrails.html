Agents / Action gate

WORKBENCH / ACTION GATE

Layer the defenses.

Eleven actions an agent might propose in the fictional world. Seven should never happen; four are legitimate. Switch defenses on and watch two numbers: harmful actions that still execute, and legitimate work that gets stopped. The decisions come from the same rules as tracks/agents/lab/guard.py.

Defenses, all enforced in code

Presets:
Harmful actions executed–should be 0
Legitimate actions stopped–the cost of the defenses
Held for a person–need a human decision

What to notice

  • “Approval only” stops the two unapproved rollbacks. Changed fields, the duplicate retry, the auto-approved ticket from the imported note, the restricted search and the outside email all still get through.
  • The outside email has a real human approval. Only the egress allowlist stops it: a tired approver is not a security boundary.
  • With all six defenses, nothing harmful executes, but the legitimate internal handover is held. Defense in depth has a cost; decide where you accept it.
  • Every defense here works even if the model is completely fooled, because none of them asks the model.
