COURSE GUIDE

Build, evaluate and operate AI agents

Twenty-eight learning weeks, three one-hour sessions a week, one evolving project: an ops agent for the same fictional streaming platform as the RAG course. You start with a loop you can read in one screen and finish with a supervised pilot that has traces, a release gate, approvals and a kill switch.

What you will be able to do

  • Write an agent loop against a real tool-calling model, with budgets and named stop reasons.
  • Design tools models call correctly, serve them over MCP and make side effects safe to retry.
  • Measure and manage context, checkpoint long tasks and add memory only where it helps.
  • Threat-model an agent, test prompt-injection defenses and enforce approvals in code.
  • Evaluate agents on end states and trajectories, and report reliability as pass@k and pass^k.
  • Decide with numbers between a workflow, a single agent, multiple agents and a framework.
  • Trace, cost, recover and roll out an agent with the least autonomy that is useful.

How a week works

Each week has three sessions. Session A starts and inspects: run something, read code or traces, predict. Session B builds or changes one thing. Session C runs and verifies with tests and measurements. Each week ends with what to save and when to move on, followed by an ungraded quick check. Mark sessions complete in the lesson; progress is stored in your browser and can be exported.

Before you start

You need Python 3.10 or newer, Git and either a machine that can run a small local model or access to a cloud model provider. Node is needed only to run the site's parity tests. The RAG course is recommended but not required. Read What an AI agent is first, then the project contract.

What this course leaves out

Training or fine-tuning models (covered in RAG Modules 5–6), computer-use and browser agents, and voice. The loop, tool, guardrail and evaluation skills here carry over to all of them.
